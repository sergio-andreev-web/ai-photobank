# Пакет 05 — интеграция, контракты и приемка

**Владеет:** `tests/contracts/**`, `tests/e2e/**`, приемочные сценарии и отчеты о несовместимости. Начинает подготовку фикстур после фиксации контрактов; полную интеграцию — после независимых реализаций.

**Источник:** [исходное ТЗ](../technical-specification.md), оба OpenAPI, JSON Schema и результаты пакетов 01–04.

**Сделать:** проверки Nuxt ↔ Laravel и Laravel ↔ mock AI; сценарий из §75; тест того, что AI недоступен, но upload и tag search продолжают работать; duplicate, retry, reprocess, suppression, модерацию candidates; проверки Mac/CPU и позже RunPod; измерение целевых задержек без cold start. Эталонный набор 300–500 фото и оценка precision/recall — отдельная приемочная работа с ручной разметкой.

**Результат:** воспроизводимый сценарий от чистого setup до поиска и модерации; отчеты с конкретным владельцем и контрактным расхождением для каждого сбоя.

**Граница:** не переписывать чужие модули напрямую; исправления возвращаются владельцам. Реальные GPU-тесты не включать в обычный CI.
