# ADR-0013: Корзина и восстановление изображений

Статус: Accepted (владелец продукта, 2026-09-30)

## Контекст

Удаление — soft delete (§78, ADR-0006): файлы и история анализов остаются, но в интерфейсе удаленное фото было
недоступно навсегда. Повторная загрузка того же файла получала `IMAGE_ALREADY_EXISTS` со ссылкой на удаленное
изображение, которое открывалось с 404 — тупик.

## Решение (контракты 1.6.0)

- `GET /api/admin/images/trash` — удаленные изображения, deleted_at desc, id desc; элемент — ImageSummary +
  `deleted_at`.
- `POST /api/admin/images/{image}/restore` — снимает soft delete и пересчитывает счетчики партии; ответ —
  ImageDetail. Для неудаленного изображения — 200 без изменений; нет изображения — 404 `IMAGE_NOT_FOUND`.
- `IMAGE_ALREADY_EXISTS` получает `details.existing_image_deleted` — frontend предлагает восстановить.
- Media отдается и для изображений в корзине (дополнение к ADR-0011), иначе корзину нельзя просмотреть. Прочие
  операции над удаленным изображением по-прежнему дают 404.
- Окончательное удаление файлов остается вне MVP (§78).
