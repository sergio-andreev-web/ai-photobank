# ADR-0016 — исследование объектов по изображению

Статус: Accepted. Основание: запрос владельца 2026-09-30 на универсальный MCP/Playwright поиск.
Совместная задача: контракты, backend, frontend, инфраструктура и новый сервис `services/web-research`.
Контракт 1.11.0, совместимое добавление; существующий AI API не меняет поведение.

Настройка `object_research_enabled` по умолчанию false. Провайдер по умолчанию `codex_cli`;
доступны также `claude_cli`, `openai_api`, `anthropic_api`, `ollama` (Qwen3.5 4B).
Ollama — настраиваемый HTTP endpoint, Mac/Linux CPU/NVIDIA; модель не зависит от Apple MPS. Секреты только в окружении сервиса.
Галочка разрешает передачу превью внешнему поисковику/агенту после достижения image.ready.
Ручной запуск доступен независимо от галочки, только для ready с превью. Включение не запускает
старые изображения. Reprocess не повторяет автоматический поиск. На изображении одновременно один запуск;
повторный POST возвращает существующий активный запуск (202). История сохраняется.
Отключение предотвращает еще не начатые автоматические задания; начатые могут завершиться.
Результат не меняет caption, людей или canonical tags. Идентификация людей по лицам исключена.

Сервис получает base64 bytes превью, MIME и вопрос, не storage keys/ID пользователей/БД.
MCP инструменты inspect_image, visual_search, read_source доступны каждому адаптеру.
Playwright загружает изображение в Google Lens и открывает публичные источники. Нет категорий предметов
в алгоритме. CAPTCHA/изменение поискового интерфейса дают явную ошибку, без обхода блокировок.
Ограничены время, число источников и размер ответа. Ссылки результата должны быть реально прочитаны агентом.
Недостаток свидетельств дает uncertain, а не выдуманное точное название.

POST /v1/research требует bearer WEB_RESEARCH_TOKEN; /health открытый. Таймаут 180 с;
backend выделяет очередь images.research (worker timeout 210 с). Задания не повторяются автоматически:
новый ручной запуск — явная повторная передача изображения. Удаленное изображение не отправляется.
Потерянное задание или прерванный worker определяется по 5-минутной давности при чтении/новом запуске.

Публичные операции: GET/PATCH /api/admin/settings; GET/POST /api/admin/images/{image}/research.
GET settings не раскрывает ключи. Доступность провайдеров проверяется сервисом, failure не мешает загрузке.
Ошибки POST: IMAGE_NOT_FOUND (404), IMAGE_NOT_RESEARCHABLE (409), WEB_RESEARCH_UNAVAILABLE (503).
История: queued → running → succeeded | failed; queued automatic → cancelled при выключении.
Все даты UTC. History endpoint возвращает последние 20 запусков, новые первыми.
