# ADR-0012: Похожие изображения

Статус: Accepted (владелец продукта, 2026-09-30)

## Контекст

Администратору нужно из карточки фото найти похожие (дубли, серии одного объекта). Image embeddings SigLIP2 уже
хранятся (ADR-0009), AI для этого не нужен.

## Решение

- `GET /api/admin/images/{image}/similar?page&per_page` → `ImageList` (контракты 1.5.0).
- Ранжирование по cosine similarity image embedding активной версии (`1 - cosine_distance`), только не удаленные
  изображения с активным embedding той же версии; само изображение исключается; сортировка similarity desc, id asc.
- Порог `SIMILAR_MIN_SIMILARITY`, стартовое значение **0.7**. Замер на 21 фото (2026-09-30): одна серия или один
  сюжет — 0.73–0.91 (фигуристки 0.79–0.91, ключи 0.89, футболисты 0.73), случайные пары — 0.40–0.65.
- Нет активного embedding (фото еще не обработано) → пустая страница, не ошибка; нет изображения → 404
  `IMAGE_NOT_FOUND`.
- `semantic_score` не возвращается: список — навигация, а не отладка поиска.
