# ADR-0002: Соглашения public API — ресурсы, коллекции, фильтры, ошибки, трассировка

- Статус: Proposed
- Дата: 2026-09-25
- Затрагивает: backend, frontend, QA; все операции `public-api.openapi.yaml`

## Контекст

ТЗ дает примеры одиночных ответов без обертки (§26 `{id, status}`, §49 batch), стандартную ошибку (§51) и требует
`trace_id` у каждого запроса (§64). Формат коллекций, пагинация, фильтры и сортировка не заданы (§53 перечисляет
только фильтры экрана).

## Варианты коллекций

- A. `{data: [...], meta: {page, per_page, total, last_page}}` — offset-пагинация (рекомендуется).
- B. Laravel `LengthAwarePaginator` как есть (`current_page`, `links`, `from`, `to`, ...) — привязывает frontend к Laravel.
- C. Cursor-пагинация — лучше для больших таблиц, но grid с номерами страниц и `total` для dashboard сложнее.

## Рекомендация

- Одиночный ресурс — объект без обертки; коллекция — вариант A. `last_page = 1` при `total = 0`;
  страница за пределами — пустой `data`, не ошибка.
- `page` ≥ 1 (по умолчанию 1); `per_page` 1..100 (по умолчанию 50, как в примере §42); для `GET /api/admin/tags` —
  до 500, чтобы frontend мог построить дерево одним запросом.
- Фильтры — query-параметры с именами полей (`status`, `batch_id`, `type`, `created_from`/`created_to` RFC 3339,
  `[from, to)`); множественные значения — `tag_ids[]=1&tag_ids[]=2` (формат Laravel).
- Сортировка — `sort` с перечисленными в OpenAPI значениями, `-` = по убыванию; неизвестное значение — 422.
- Даты — RFC 3339 UTC; ID — int64; денормализованные счетчики (`images_count`, `occurrences_count`) — целые ≥ 0.
- Ошибка — §51; `details.fields` для `VALIDATION_ERROR`: объект «поле → массив сообщений» (сообщения для
  показа рядом с полем, а не для логики). Неизвестные коды клиент обрабатывает по HTTP-статусу.
- Трассировка: Laravel принимает входящий `X-Request-ID` (если формат валиден, `^[A-Za-z0-9._:-]{1,128}$`) или
  генерирует UUID; возвращает его в заголовке `X-Request-ID` каждого ответа и в `error.trace_id`; передает тот же
  ID в AI (`X-Request-ID`) для синхронных вызовов (search). Для фоновых задач — отдельный ID на вызов AI,
  связанный в логах с image_id.
- Клиент игнорирует неизвестные поля ответа.

## Последствия

- Backend оборачивает Laravel paginator в формат A (resource collection).
- Frontend может генерировать типы из OpenAPI; mock server строится из тех же схем.

## Вопросы

1. Утвердить формат A и значения per_page (50/100, теги 500)?
2. Нужна ли сортировка по `original_name`/`file_size` в библиотеке изображений?
