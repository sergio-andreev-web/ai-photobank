# ADR-0014: Скачивание оригиналов архивом

Статус: Accepted (владелец продукта, 2026-09-30)

## Контекст

Администратор выбирает фото в галерее (массовые действия) и хочет получить оригиналы. Один оригинал уже отдается
`/api/media/images/{image}/original` (ADR-0011); для набора нужен архив.

## Решение (контракты 1.8.0)

- `POST /api/admin/images/download` с `{image_ids: [...]}` (1..100, уникальные) → `application/zip`,
  `Content-Disposition: attachment; filename="photobank-YYYYMMDD-HHMMSS.zip"`. POST, а не GET: список ID и защита
  CSRF как у прочих действий.
- Без сжатия (store): фото уже сжаты, архив собирается быстро. Архив пишется во временный файл и удаляется после
  отправки; памяти не требует.
- Имя файла в архиве — `original_name`; повторы получают суффикс « (2)», « (3)» перед расширением.
- Ограничения: до 100 изображений и 2 GiB суммарно; несуществующие/удаленные ID — 422 `VALIDATION_ERROR`
  (`details.fields.image_ids`); оригинала нет в хранилище — 404 `MEDIA_NOT_AVAILABLE`.
- Один оригинал из карточки скачивается прямой ссылкой на media с атрибутом `download`, без нового API.
